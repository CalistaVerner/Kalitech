# Engine JS Modules

Этот каталог содержит JS-модули движка, которые экспортируют стабильный API для игрового кода.

## Общие методы для модулей

Чтобы уменьшить повторяемость и повысить стабильность, общие функции вынесены в
`helpers/ModuleCommon.js` и используются в модулях-обёртках.

Доступные функции:

- `requireEngineApi(engine, methodName, moduleTag)` — типовая проверка наличия
  `engine.<methodName>()` с едиными ошибками и безопасным получением API.
- `normalizeCfgObject(cfg)` — приводит конфиг к объекту (`{}` при некорректном значении).
- `normalizeNullableObject(cfg, moduleTag, label)` — допускает `null/undefined`,
  иначе требует объект и выбрасывает читаемую ошибку.

Используйте эти функции в новых и существующих модулях, чтобы убрать дублирование
проверок и обеспечить одинаковое поведение во всех обёртках.
